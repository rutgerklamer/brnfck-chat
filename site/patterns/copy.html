Brainfuck can only read a cell by emptying it. So the first loop pours the value into two cells at once: the copy and a helper.

The second loop pours the helper back into the original. Now the value stands in two places and the helper is empty again.

A helper cell that is empty before and after is called a scratch cell.

What it needs

  • One scratch cell that is zero. It is zero again at the end.
  • The copy is added to the target: clear the target first if it may hold something.
  • Any cell size. The pointer ends where it started.
Common mistakes
  • Using a scratch cell that is not empty. The original then comes back too large.
  • Forgetting the second loop. That is the form Into two cells at once of move a value, and the original is gone.
