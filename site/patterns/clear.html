Watch it run

The form “Count down” works on one cell, named “x”. Press Play, drag the step slider forwards and back, or change x with the slider:

The loop takes 1 from the cell and asks "is it zero?". It goes round until the answer is yes.

So the plain cost grows with the value: two steps for every unit. An optimising interpreter sees a loop that only counts its own cell down and sets the cell to zero in one step.

What it needs

  • Any cell size. No scratch cells. The pointer does not move.
  • On cells that do not wrap, the value must not be negative, or [-] never ends.
Common mistakes
  • Forgetting it before a "set to a constant". +++ adds 3, it does not set 3.
  • Clearing a cell that is known to be zero already. It is harmless, but it is one more step every time.
  • Using [+] on wide cells: it counts up to the top, which takes billions of plain steps on 32-bit cells.

What it costs
