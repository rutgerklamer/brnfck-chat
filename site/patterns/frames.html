Watch it run

The form “y = 3 × x in every frame” works on 19 cells; the named ones are “scratch”, “marker”, “x”, “y” and “tmp”. Press Play, drag the step slider forwards and back, or change frames and first x with the sliders:

A program that is written out for 512 places is 512 times as long. Length is a real cost here: the chat program is a file you have to load.

Moves in brainfuck are relative, so a piece written for the first place works at every place. The tape is cut into equal stretches, frames, and a loop does the piece and then steps one frame on.

One flat loop first puts a marker in every frame. The walking loop takes the marker away as it goes and stops at the first frame without one. That costs 2 steps more per frame than writing the piece out.

What it needs

  • Frames of equal length; the piece may use only cells of its own frame, scratch cells included.
  • One marker cell per frame, zero outside the call, and a zero cell where the next frame would start. One scratch cell for laying the markers.
  • Any cell size: this pattern does not need wrapping.
Common mistakes
  • A piece that reaches into the next frame for scratch space.
  • Forgetting that results must leave the frame by being carried: see the form A running total that travels along of walk an array of records.
