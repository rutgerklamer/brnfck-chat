If and else

Runs one piece of program when a cell is not zero and another piece when it is zero.

Watch it run

The form “Flag next to x” works on 5 cells, named “x”, “flag”, “zero”, “then” and “else”. Press Play, drag the step slider forwards and back, or change x with the slider:

A flag next to x starts at 1. If x is not zero, the first loop runs the "then" part, clears the flag and stops on the flag cell.

One step to the right is then a zero cell, so the second loop is skipped. If x was zero the first loop is skipped, that same step lands on the flag, which is still 1, and the "else" part runs.

Both ways end on the same cell. That is the whole trick: after a decision the program must know where the pointer is.

What it needs

  • Main form: flag and one more zero cell directly right of x. Both are zero at the end; x is kept.
  • Each part starts and ends on a fixed cell (here: the "then" part on x, the "else" part on the flag).
  • Any cell size.
Common mistakes
  • Changing x inside the "then" part. The first loop leaves through the flag cell, not through x, so that is allowed, but the layout must stay x, flag, zero.
  • Running two separate ifs, "if x" and "if not x", when the first one changes x.
