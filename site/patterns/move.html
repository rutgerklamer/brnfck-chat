Watch it run

The form “To the next cell” works on 2 cells, named “x” and “y”. Press Play, drag the step slider forwards and back, or change x and y with the sliders:

Each round takes 1 from the source and gives 1 to the target. The loop stops when the source is zero, so by then everything has arrived.

The target gets the value added. If it held 2 before, it holds 2 more than the source did.

A loop like this one only adds and moves and comes back to where it started. That is called a flat loop. An optimising interpreter does it in one step.

What it needs

  • Any cell size. No scratch cell.
  • The loop must end on the cell it started on: as many > as <.
  • Clear the target first if you want "set", not "add".
Common mistakes
  • Unequal numbers of > and <. The loop then tests a different cell every round and wanders off.
  • Expecting the source to survive. Use copy a value for that.
