Watch it run

The form “A few cells seeded by one loop” works on 7 cells; the named ones are “counter”. Press Play, drag the step slider forwards and back, or edit the text:

A letter is printed by making its code in a cell. Making each code from zero is long: "H" alone is 72 plus signs.

Shorter: keep the cell and walk from one letter's code to the next. "l" to "o" is three plus signs.

Shorter still: one loop first puts a round number in each of a few cells (near 30 for spaces, near 70 for capitals, near 100 for small letters). Each letter is then a short walk from the nearest cell. The classic "Hello World!" program is built this way.

What it needs

  • One cell, or a handful: one per group of letter codes. They are left holding the last letters.
  • Any cell size. The text is fixed when the program is written.
Common mistakes
  • Clearing between letters. The whole gain comes from keeping what is there.
  • Counting on wrapping to reach a far letter the short way round: that makes the program depend on 8-bit cells.
