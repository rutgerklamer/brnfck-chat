Echo until the end of the input

Prints everything it reads and stops when the input ends, on any interpreter.

Watch it run

The form “For all three conventions” works on 3 cells; the named ones are “zero” and “letter”. Press Play, drag the step slider forwards and back, or edit the input:

The loop itself is simple: read, and while there is a letter, print it and read again. The hard part is "while there is a letter".

Brainfuck never fixed what , does when the input is over. Some interpreters put 0 in the cell, some put −1, some leave the cell as it was. A program that only knows one of the three hangs on the others.

The portable form covers all three. It clears the cell before each read, so "left as it was" becomes 0. And it tests each letter twice: is it 0, and is it 0 after adding 1 (which catches −1).

What it needs

  • Portable form: one zero cell on each side of the working cell. It starts on cell 0 and reads into cell 1.
  • The pointer ends on cell 1 when the end was 0 or "no change", and on cell 0 when it was −1.
  • A byte with all bits set (255) in the input ends the portable form early.
Common mistakes
  • Testing a program with one interpreter only. Use the choice "At the end of the input, the comma gives", in More controls under the first figure, to try all three answers.
  • Using ,[.,] where the end of the input is −1: it prints the byte 255 for ever.
