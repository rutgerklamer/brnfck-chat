A loop is the only thing in brainfuck that looks at a cell. So an "if" is a loop that is made to run at most once.

The simplest way to stop it after one round is to clear the cell at the end of the body. That destroys the value.

To keep the value, either test a copy (see copy a value), or leave the loop by stepping onto a cell that is known to be zero and then find the way back.

What it needs

  • Destroying form: nothing. Copy form: two scratch cells. No-copy form: a zero cell on each side of x.
  • The body must come back to the cell it started on.
  • Any cell size.
Common mistakes
  • Leaving the loop on another cell than the one you entered on, and then moving as if you knew where you are. See the note "Wrong as often given" under this list.
  • A body that changes the tested cell and forgets that the closing bracket tests it again.

Wrong as often given

A short form that is often given is "x[ code temp ]x": leave the loop by walking to an empty cell, then walk back to x. Written with fixed moves this is wrong when x is zero: the loop is skipped, the pointer is still on x, and the walk back goes one cell too far. The form Keeping x, without a copy on this page repairs it with [<], which stops on the zero cell left of x in both cases.

Each wrong form is run, and it fails in exactly this way.
