Watch it run

The form “acc gets a × b added” works on 11 cells; the named ones are “a”, “b” and “acc”. Press Play, drag the step slider forwards and back, or change a and b with the sliders:

This is long multiplication in base 2. Read a bit by bit with the bit peel. For every set bit j, add b × 2ʲ to the answer.

b × 2ʲ is the pattern multiply by a constant, a flat loop: one step, and b is kept with a second step.

The top bit of a signed number counts negative, so for that one bit the same loop subtracts. Nothing else is needed for negative numbers.

So the cost is about 25 steps for the eight tests and 5 more for every set bit of a: 28 to 60 in all, whether b is 7 or 7 million.

What it needs

  • Cells that wrap at a known width. The program text is made for that width (8, 16 or 32 bits) and gives wrong answers on any other.
  • To be fast it needs an interpreter that does a flat loop in one step. In plain steps the shifts are long loops and the gain is lost.
  • Eight scratch cells. a is read as a signed 8-bit number; b may be any value. Both are kept.
Common mistakes
  • Peeling the wider of the two numbers. The cost follows the bits of a: peel the narrow one.
  • An a outside −128…127: only its low 8 bits are used.
