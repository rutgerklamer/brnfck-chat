Reference

Brainfuck is a programming language with eight commands, made by Urban Müller in 1993 for the Amiga computer [1]. It is a well-known “esoteric” language: one made to explore an idea, not to get work done [2]. To learn the language step by step, begin with Start here.

Brainfuck in five minutes

This program prints “Hello, World!” and a new line, in 136 commands. Press Play and raise the speed, or drag Step to any moment of the run, and watch the cells and the line “Printed”:

Notice cells 1 to 4: a loop filled them with 70, 100, 30 and 10, and the rest of the program nudged those numbers to the letters it needed. The machine has a long row of boxes, the tape. Each box, a cell, holds a number and starts at 0. A pointer marks one cell. A program is a line of commands, read from left to right. There are eight commands, and that is the whole language:

The eight commands. The last column is how the 1993 README writes each one in the language C [1].
CommandWhat it doesIn C
>Move the pointer one cell to the rightp++;
<Move the pointer one cell to the leftp--;
+Add one to the cell under the pointerarray[p]++;
-Take one off the cell under the pointerarray[p]--;
.Print the cell as one characterputchar(array[p]);
,Read one character into the cellarray[p]=getchar();
[Start of a loop: if the cell is 0, jump past the matching ]while(array[p]) {
]End of a loop: go back to the matching [}

Three more things and you know it all:

  • Letters are numbers. A cell that holds 72 prints as "H", because 72 is the code for H in the ASCII table.
  • A loop runs while the cell under the pointer is not 0. It is the only way to repeat something and the only way to decide something.
  • Every other character is a comment. The README says it in one sentence: "All other characters are ignored." [1]

That the language is small does not make programs small. Printing thirteen characters took 136 commands in the program above. The shortest program known to print that greeting has 72 [3].
