    The machine of every lesson

    This program prints "Hi". Press Play, or drag the Step slider back and forth, and watch which cell is outlined:

    The line on top is the program, and the marked command is the one that runs next. The row under it holds the numbers the program works on, and the outline shows which of them it is working on right now. Every lesson uses this same machine.
