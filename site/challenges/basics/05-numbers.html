Eight times nine

A letter needs a number like 72 or 105, and typing that many plus signs is long. This program of 24 commands prints the letter H, number 72. Press Play, or drag the slider through the steps, and watch cell 0 and cell 1 while the loop runs:

Notice that every round took 1 off cell 0 and put 9 onto cell 1, and that the loop stopped when cell 0 reached 0. Eight rounds of 9 make 72, the number of the letter H. Typing 72 plus signs needs 73 commands with the full stop; this program needs 24.

This is a loop that multiplies. A counter sits in one cell, the loop adds a fixed number to the next cell every round, and a step to the right then reaches the result. If your number is not a neat product, add or take off the rest after the loop.

Sixty-five

Now you build the number. Write a program that prints the letter A, which is number 65, with at most 30 commands:

For example ++++++++[>++++++++<−]>+.: eight eights, and one more. There are many right answers; 5 × 13 works too.

Looking for the shortest program is a sport called code golf. The Challenges keep score for you, if you like that.

Hi

The box holds the program of the first figure, which prints H. Add to it so that it prints Hi. The small letter i is number 105:

From 72 to 105 is 33 up. You can walk there with 33 plus signs, or run a second loop that adds to the same cell. What you should not do is start again from zero: the cell already holds a number near the one you need.

That is the whole art of printing text in brainfuck: go from each character to the next by a short way.

Your own word

Type a word in the first box, then write a program that prints exactly that word. The chart of Lesson 3 gives the numbers:

You have written a program that says something nobody told you to say. Every text a brainfuck program prints is made like this: a cell that holds a number near the next letter, and a walk from letter to letter.

The last hint writes a program for your word by itself. It is not the shortest possible; can you beat it? The classic first program in any language prints “Hello, World!”, and it is one of the Challenges: Hello, World!
